# MOODI · 내 감정 기록

첨부된 20개 화면과 박영민 스토리보드를 바탕으로 만든 모바일 웹앱입니다.

## 확인하기

- 배포: https://moodi-cloud-diary-ym.flowyamber.chatgpt.site (Sites 소유자 로그인 필요)
- 로컬: index.html을 브라우저로 열거나 `python3 -m http.server 8000` 실행 후 http://localhost:8000 접속
- 휴대폰에서는 배포 링크를 열고 브라우저의 '홈 화면에 추가'를 사용할 수 있습니다.

## 구현 기능

감정 9종 선택, 제목·내용 필수 검사와 2,000자 제한, 카메라·앨범 사진 최대 3장 첨부 및 삭제, 기록 저장·상세·수정·삭제 확인, 월 탐색, 제목·내용 검색, 감정 필터, 주간·월간·연간 집계와 비율, 프로필 닉네임 변경, 기록 JSON 백업을 제공합니다. 사진은 긴 변 1,000px로 압축합니다.

통계는 현재 브라우저의 실제 기록을 집계합니다. 첫 실행에는 명시된 예시 기록 3개가 표시되며 프로필에서 지울 수 있습니다. 주간 통계는 선택일을 포함한 7일, 월간은 해당 달, 연간은 해당 연도 기준입니다. 통계에서 감정을 선택하면 해당 월의 감정 필터 목록을 엽니다. 연간은 해당 감정이 있는 첫 달을 엽니다.

## 체험 버전 범위

- 기록과 사진은 localStorage에 저장됩니다. 같은 기기·브라우저·주소에서 유지되며, 브라우저 데이터 삭제 시 사라집니다. 중요한 기록은 JSON으로 백업해주세요. 기기 간 동기화 및 백업 복원은 제공하지 않습니다.
- 카카오·Apple·이메일 인증은 아직 연결되지 않았습니다. 로그인·가입 화면은 안내가 표시되는 UI 체험용이며 입력한 이메일·비밀번호를 저장하거나 전송하지 않습니다.
- 기록 알림 시간은 설정값만 저장합니다. 실제 자동 푸시와 앱 잠금은 제공하지 않습니다.
- App Store/Play Store 네이티브 앱이 아닌 반응형 웹앱입니다. 구름 캐릭터와 노을 그림은 참고 디자인을 바탕으로 SVG/CSS로 재현했습니다.

## 소스 수정

루트의 index.html, style.css, app.js를 수정한 후 dist/에 같은 파일을 복사합니다. dist/가 Sites 배포 대상입니다. 빌드 도구나 서버 의존성이 없습니다.
